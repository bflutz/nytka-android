# Upload only on Wi-Fi (unmetered networks)

Phase 1 ([plan](https://github.com/bflutz/nytka-server/blob/phase1/docs/voice-recorder-plan.md), R3). `capture/UploadDrainWorker.kt:65` uses `NetworkType.CONNECTED`, so it uploads on mobile data too. Barend wants batched uploads on Wi-Fi only. The phone holds the queue until it gets home (or any Wi-Fi) and deletes a batch only after the server confirms it.

**Change:**
- Use `NetworkType.UNMETERED` for the drain worker by default.
- Add a setting, 'Upload on mobile data', default off, that switches back to `CONNECTED`.
- Show 'waiting for Wi-Fi' in the queue status when batches wait for that reason.

**Done when:**
- A unit test shows the work request's constraints follow the setting.
- Delete-after-confirm is unchanged.
- The device docs are updated; the oss build, unit tests and ktlint pass.

# Opus at 16 kbps, 16 kHz mono for phone-mic recordings

Phase 1 ([plan](https://github.com/bflutz/nytka-server/blob/phase1/docs/voice-recorder-plan.md), R1). The phone-mic encoder uses `BIT_RATE = 32_000` (`app/.../phonemic/OpusEncoder.kt`). Barend wants ~16 kbps for speech, which halves upload and storage.

**Change:**
- Set the bitrate to 16 kbps, keeping 16 kHz mono, 20 ms frames and VOICE_RECOGNITION.
- Set the encoder's complexity and VBR where the API allows, so speech stays clear.

**Done when:**
- Unit tests are updated: an encoded 10 s fixture is between ~15 and ~25 KB and still decodes at 16 kHz mono.
- `docs/reference/device.md` says 16 kbps.
- `./gradlew :app:compileOssDebugKotlin testOssDebugUnitTest ktlintCheck` passes.
